# 初代怪兽对战

初代奥特曼 39 话里的怪兽 3v3 对战，纯 HTML/CSS/JS，无框架无构建。

## 玩法

- **怪兽对战**：3v3 打 AI，编成点数上限 20，每只带 4 个技能
- **侵略地球**：三轮连打，最后对初代奥特曼
- **图鉴**：查看所有角色和技能
- **教程**：九步讲完机制再实战

## 机制

- 技能类型：格斗 / 光线 / 姿态（反制 A 挡光线、反制 B 挡格斗）/ 大招 / 被动
- 破姿态 ×1.6
- 对波：双方同出光线时比较伤害差值，可追加 EP 反击
- 类型克制：宇宙人克全体怪兽，怪兽三环
- 状态：迟缓、眩晕、击退、浮空、混乱、倒地、中毒、钳制、切割
- 领域与羁绊
